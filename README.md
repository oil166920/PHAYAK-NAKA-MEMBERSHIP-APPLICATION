## สำคัญ
รุ่นนี้เป็นเว็บไซต์ Frontend แบบไม่ใช้เซิร์ฟเวอร์ ข้อมูลใบสมัครเก็บใน LocalStorage ของเบราว์เซอร์ ดังนั้น `/admin` จะเห็นข้อมูลจากเครื่อง/เบราว์เซอร์ที่รับสมัครเท่านั้น และไม่ควรใช้รหัสผ่านนี้กับระบบจริงที่มีข้อมูลสำคัญ

การส่งข้อมูลเข้า Facebook/เพจแบบอัตโนมัติทำไม่ได้จากหน้าเว็บทั่วไปโดยไม่ใช้ระบบ API/การยืนยันสิทธิ์ของ Meta; ปุ่มจึงเปิด Facebook/เพจ และมีปุ่มคัดลอกข้อมูลเพื่อให้ผู้สมัครหรือผู้ดูแลส่งข้อความด้วยตนเอง

## เปิดใช้งาน
แตก ZIP แล้วเปิด index.html สำหรับหน้าสมัคร
ถ้านำขึ้นโฮสติ้ง ให้เข้าที่:
https://โดเมนของคุณ/admin

หากโฮสติ้งไม่รองรับการ rewrite เส้นทาง `/admin` ให้เปิด `https://โดเมนของคุณ/index.html` แล้วระบบจะยังมีหน้าสมัครตามปกติ; สำหรับ `/admin` ควรตั้ง rewrite ให้ชี้กลับ `index.html`
